## Scope

Selected the core value-flow contracts; 19 entry points across 3 contracts:

| Contract | Handlers | Notes |
|---|---|---|
| `RewarderHub` | pushReward, batch, claim, claimBatch, freeze/unfreeze, recoverFrozenFunds, withdrawExcess, donateERC20 | Central custodial accounting (UUPS/ERC1967 proxy) |
| `CampaignBank` | deposit, withdraw, updateAllowance(+s), revokeAllowance(+s), setOpen | Per-merchant escrow (clone) |
| `mUSDToken` | mint, transfer, transferFrom, approve | Reward token (in-repo mock USD) |

**Excluded** (documented in `coverage-targets.md`): `CampaignBankFactory` (bootstrap), the WebAuthn/kernel
ERC-4337 passkey validators (need valid secp256r1 signatures, disconnected from value invariants),
and the unused `BetaDistribution`/`MPT` math libraries.

## Setup

`Base.sol::setup()` deploys the production topology: a `RewarderHub` behind an ERC1967 proxy
(matching `script/Deploy.s.sol`), a `CampaignBank` clone bound to the hub, two standard ERC20 reward
tokens (mUSD + a MockERC20), and 3 actors. The admin holds `REWARDER_ROLE` + `COMPLIANCE_ROLE` and
owns the bank; the bank is funded and pre-approved so the hub can pull rewards.
